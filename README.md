# ごみ出しカレンダー（非公式）

町の「令和8年度 家庭用 資源とごみの収集カレンダー」をもとに作った、スマホ用のウェブアプリです。
iPhone でも Android でも使えます。今日・明日のごみ、次の収集日、月カレンダー、出し方ガイドが見られます。

## ファイルの説明

| ファイル | 内容 |
| --- | --- |
| `schedule.json` | **収集日のデータ。直すのはこのファイルだけです** |
| `index.html` `style.css` `app.js` `logic.js` | アプリ本体（通常は触りません） |
| `sw.js` `manifest.webmanifest` `icon-*.png` `apple-touch-icon.png` | ホーム画面への追加・オフライン表示のためのファイル |

## 公開のしかた（GitHub Pages・無料）

1. https://github.com でアカウントを作る（無料）
2. 右上の「＋」→「New repository」。名前は半角英数字で（例：`hinode-gomi`）。**Public** を選び「Create repository」
3. 「uploading an existing file」をクリックし、**zip を展開した中のファイルすべて**（フォルダごとではなく、`index.html` などのファイルそのもの）をドラッグ＆ドロップ。下の「Commit changes」を押す
4. 上の「Settings」→ 左の「Pages」→ Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして「Save」
5. 1〜2分待つと、同じ画面に公開URL（`https://ユーザー名.github.io/リポジトリ名/`）が出ます

※ GitHub の画面の表記は、変わることがあります。

## ホーム画面に追加する

- **iPhone**：Safari でURLを開く → 共有ボタン（□に↑）→「ホーム画面に追加」（Chrome ではなく **Safari** で）
- **Android**：Chrome でURLを開く → 右上のメニュー（︙）→「ホーム画面に追加」または「アプリをインストール」

## データの直しかた

GitHub のリポジトリで `schedule.json` を開き、右上の鉛筆アイコンで編集 → 「Commit changes」。1〜2分で、みんなの画面に反映されます。

```
"2026-06-16": ["nonburn", "smallelec"],     ← この日は不燃ごみと小型電子機器
"2026-12-31": [],                           ← この日は収集なし（行を消してもOK）
```

**例：6月の不燃ごみが 16日 → 23日に変わった**
`"2026-06-16": ...` の行を消し、`"2026-06-23": ["nonburn", "smallelec"],` の行を足します。行の並び順は関係ありません。

**種類のコード**

| コード | ごみの種類 | コード | ごみの種類 |
| --- | --- | --- | --- |
| `burn` | 可燃ごみ | `resB` | 資源B（缶・金属類、びん類） |
| `nonburn` | 不燃ごみ | `pet` | ペットボトル |
| `smallelec` | 使用済小型電子機器 | `tray` | 白色トレイ |
| `paperA` | 資源A（紙類・布類） | `harmful` | 有害ごみ |

**書くときの注意**
- 日付とコードは、半角の `"` で囲む
- 各行の最後に `,`（カンマ）を付ける。ただし `"days"` の**一番最後の行だけは付けない**
- 全角の記号や空白を混ぜない

**お知らせの出し方**：`"notices"` に1行足します（`from` の14日前から `to` まで、ホームの上に表示されます）。

**書き間違えたとき**：アプリは前回の正しいデータを表示し、画面に注意が出ます。GitHub の「History」から前の状態に戻せます。
